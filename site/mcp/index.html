Kvit MCP · tilslutning

Kobl din AI-assistent på Kvit

Kvit leveres med en MCP-server. Den kører ved siden af programmet på din egen maskine, og du giver din assistent én adresse. Så kan den svare på, hvad der forfalder, hvad du står i banken, og hvad momsen bliver, og bogføre de rutineposter, du beder om. Nøglen bliver på serversiden.

Tilslut

Denne side: adressen, konfigurationen pr. klient, og det, der driller.

Værktøjer

Alt, assistenten kan læse og skrive, genereret fra serveren selv. Og de tre ting, den ikke kan.

Opbygning

Få filer, to afhængigheder, ingen adgang til databasen. Reglerne og testene.

Før du starter

Du skal bruge to ting. Et API-token: installationen og den selvstændige version spørger om det og laver et, hvis du bare trykker Enter. Kører du fra kildekode, sætter du API_TOKEN i .env (mindst 16 tegn). Og programmet skal køre, for MCP-serveren åbner aldrig databasen selv; alt går gennem programmets API.

Find din adresse

Du kørerAdresseHvor den står
Docker-installationen (install.sh / install.ps1)http://localhost:3333/mcpInstallationen skriver den og konfigurationsudsnittet til sidst. Kør den igen, hvis du mistede det; data bevares.
Den selvstændige version (én fil)http://127.0.0.1:3333/mcpI terminalen ved start, sammen med en stdio-variant.
Kildekodenhttp://127.0.0.1:3333/mcp efter npm run mcp:httpServeren skriver adressen, og om tokenet er sat, når den starter.

Valgte du HTTPS i installationen, er adressen i stedet https://…:8443/mcp; installationen viser den præcise. Porten kan ændres med FAKTURA_MCP_PORT, hvis 3333 er optaget.

Sæt den ind i din klient

Claude Code

claude mcp add --transport http kvit http://localhost:3333/mcp

Det er det hele. Kør claude mcp list for at se, at den svarer.

Claude Desktop

Desktop henter kun fjernservere over https med en offentlig adresse, så en lokal server kobles på over stdio: Desktop starter selv serverprocessen. Udsnittet skal i claude_desktop_config.json (Windows: %APPDATA%\Claude\, Mac: ~/Library/Application Support/Claude/). Vælg det, der passer til din installation.

Docker-installationen (kører serveren inde i containeren, tokenet læses derinde):

{
  "mcpServers": {
    "kvit": {
      "command": "docker",
      "args": ["compose", "-f", "/sti/til/kvit/docker-compose.yml", "exec", "-i", "-T",
               "-e", "FAKTURA_URL=http://127.0.0.1:3000",
               "app", "sh", "-c", "FAKTURA_API_TOKEN=$API_TOKEN exec node mcp/dist/stdio.js"]
    }
  }
}

Den selvstændige version (programmet kører selv som MCP-server med --mcp-stdio; den præcise linje står i terminalen ved start):

{
  "mcpServers": {
    "kvit": {
      "command": "C:/sti/til/faktura.exe",
      "args": ["--mcp-stdio", "--config", "C:/sti/til/faktura.json"]
    }
  }
}

Kildekoden (efter npm --prefix mcp run build):

{
  "mcpServers": {
    "kvit": {
      "command": "node",
      "args": ["C:/sti/til/micro-finance/mcp/dist/stdio.js"],
      "env": {
        "FAKTURA_URL": "http://127.0.0.1:3000",
        "FAKTURA_API_TOKEN": "samme-vaerdi-som-API_TOKEN"
      }
    }
  }
}

Andre MCP-klienter

Alle klienter, der taler streamable HTTP, bruger adressen direkte:

{ "mcpServers": { "kvit": { "type": "http", "url": "http://localhost:3333/mcp" } } }

Klienter, der kun taler stdio, bruger et af command-udsnittene ovenfor. MCP Inspector virker også: npm --prefix mcp run inspect fra kildekoden.

Fra en anden maskine

MCP-endpointet har ikke noget login. Den, der kan nå porten, kan bruge værktøjerne, så det er bundet til din egen maskine og skal aldrig ud på internettet. Vil du bruge det fra din bærbare, går vejen over din VPN:

  • Tailscale, med installationen. Svar tailscale på HTTPS-spørgsmålet, så udgives endpointet som https://<maskine>.<tailnet>.ts.net:8443/mcp med et rigtigt certifikat, og alle enheder på dit tailnet kan bruge adressen. Installationen tilføjer selv navnet til de tilladte hosts.
  • Tailscale, uden HTTPS. Sæt MCP_ALLOWED_HOSTS=100.64.0.12:3333 (din tailnet-adresse) i .env og kør installationen igen; fra kildekode sættes MCP_HOST til tailnet-adressen. Brug præcis den adresse i klienten, serveren afviser andre (se nedenfor).

Resten, med WireGuard, firewall og Caddy, står i hosting-vejledningen (engelsk).

Det, folk snubler over

  • »url must start with https« i claude.ai eller Desktops Add custom connector. Den dialog er til servere på internettet, som Anthropic kan nå. En lokal server eller en tailnet-adresse går ikke der; brug Claude Code eller stdio-udsnittet til Desktop.
  • Alle værktøjer fejler med en auth-fejl. Serveren kender ikke tokenet, eller det passer ikke med programmets API_TOKEN. GET http://localhost:3333/healthz svarer {"ok":true,"token_configured":true}, når det er sat. Intet er sendt eller ændret, når fejlen kommer.
  • Serveren svarer ikke på tailnet-adressen. Host-headeren valideres som beskyttelse mod DNS-rebinding. Klienten skal bruge den adresse, serveren er bundet til, eller en, der står i MCP_ALLOWED_HOSTS; serveren advarer ved start, hvis listen mangler.
  • Lokal HTTPS (kvit.localhost). Certifikatet ligger i installationsmappen som kvit-root-ca.crt, og Claude Code skal startes med NODE_EXTRA_CA_CERTS pegende på det.
  • Assistenten vil udstede en faktura. Det kan den ikke, og det er med vilje. Den laver kladden, og du trykker Udsted i programmet. Mere om det under Værktøjer.

Prøv det

Når den er koblet på, kan du spørge på dansk:

  • »Hvilke fakturaer forfalder snart?«
  • »Hvad står jeg i banken?«
  • »Hvad skal jeg indberette i moms for 2. kvartal?«
  • »Registrér min saldo: 84.250 kr« – assistenten kører afstemningen og bogfører forskellen som korrektion.
  • »Bogfør bankgebyret på 45 kr fra i går.«
  • »Lav en kladde til Nordhavn Arkitekter: 12 timer rådgivning à 950 kr.«
  • »Log 2,5 timer hos Nordhavn i dag: workshop om tilgængelighed.«
  • »Hvor mange ufakturerede timer har jeg, og hvad er de værd?«
  • »Opret en udgift: Hetzner, serverhosting september, 380 kr uden moms, konto 2000.«

Alt, den skriver, står i revisionssporet med afsender api (audit_log.csv i eksport-zippen), så du altid kan se, hvad der kom fra AI'en.

Læs mere. Brugervejledningens afsnit om AI-adgang siger det samme kortere. mcp/README.md (engelsk) har miljøvariabler, .env-filer og testene for den, der vil køre serveren fra kildekode.
